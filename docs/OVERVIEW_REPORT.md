## 값의 정의

히트맵 H(c,p)는 각 필수 투입재별로 해당 국가 공급 기업 경로의 계산 배분율을 합산한 뒤 그 최댓값입니다. 실제 점유율 공개 값이 아니라 모델 가정값입니다. 기록 없는 칸은 빗금·‘데이터 없음’이며 실제 공급 0%를 의미하지 않습니다. 기록은 있지만 배분 합이 0인 경우에는 0%로 구별합니다. 툴팁은 투입재별 배분율, 경로 가용률을 곱한 가용 기여, 감소(%p)를 표시합니다. 밝기는 원래 의존도, 테두리와 ●/△/×는 직접 경로의 최악 공급 상태입니다. 이 값에는 재고·대체를 다시 더하지 않습니다. 우측 공정 점수와 영향 공정 수에는 기존 엔진이 계산한 재고·대체 결과가 그대로 적용됩니다.

국가 점 크기는 공급 또는 수요로 연결된 서로 다른 공정 수입니다. 색과 라벨 기호는 해당 국가 연결 경로의 최악 상태입니다. 양방향 국가 쌍을 하나의 호로 합치고 계산 배분율 합에 비례한 굵기를 표시합니다(상한 적용). 따라서 호 굵기는 물동량이 아닙니다. 국내 연결은 호에서 제외하되 국가 관여 공정 수에는 포함됩니다. 상위 국가는 의존도 50% 이상인 공정 수 순이며 최대 의존도, 국가명으로 동률을 정렬합니다.

## 남은 문제·해석 한계

- 국가 비중은 실제 구매·시장 점유율로 검증된 값이 아니며 현재 시연용 배분 가정입니다. 후보 관계에는 협력·과거 인증·예정 계약도 포함됩니다.
- 국가는 본사/대표 법인 기준이며 실제 공장·광산 소재지가 아닙니다.
- 히트맵의 직접 경로 감소는 재고·대체가 완충한 공정 점수와 다를 수 있습니다. 다단계 requires나 시간별 연쇄 전파 계산은 추가하지 않았습니다.
- 국가 쌍의 서로 다른 품목 비중을 합한 호는 상대적인 모델 연결 가중치입니다. 단위가 있는 물동량 데이터가 필요하면 별도 데이터가 필요합니다.
- 작은 화면에서는 세로·가로 스크롤이 필요합니다. 지구 뒷면은 회전해야 보입니다. 개별 공정 화면 구조를 유지하여 전체 모드는 별도 패널을 추가하는 방식으로 구현했습니다.
