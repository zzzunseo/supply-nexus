# 핵심 지적 2번 — 기업별 점수·최악/평균 집계 완료

2026-10-26 · 등록된 모델 범위에서 두 번째 지적을 수정했습니다. 새 기업이나 실제 팹·생산량·점유율은 추가하지 않았습니다.

## 구현

- 삼성·TSMC 전공정 7개와 ASE·Amkor 패키징 결과를 구분했습니다. 기업별 값·일별 곡선·최초 부족일·시간 평균을 제공합니다.
- 왼쪽에 최악 기업과 기업 단순평균을 동시에 표시합니다. 기존 min 값을 산업 전체 평균처럼 보여 주던 해석을 구분했습니다.
- 공정마다 등록 기업끼리 동일 비중으로 평균합니다. 실제 생산량/점유율 가중평균이 아닙니다. 전공정과 패키징의 기업을 한 분모에 섞지 않습니다.
- 미등록 기업×공정은 None/JSON null/‘— 미등록’으로 유지합니다. 삼성·TSMC의 패키징과 ASE·Amkor의 전공정을 0이나 100으로 채우지 않습니다.
- 지구본 위 ‘타임라인 점수 보기’에서 최악, 평균, 각 기업 곡선을 고릅니다. 이는 곡선의 보기만 바꾸며 시뮬레이션 조건·지도·왼쪽 비교 지수는 유지합니다.
- ‘기업별 공정 점수·모델 범위’ 창에 8개 공정 비교표, 공정별 등록 기업 수, 기업별 누락 제약과 결과 저장을 넣었습니다.
- 1번에서 표시한 불완전 범위를 기업별로 추적하고 집계에도 이어갑니다. 삼성 PR의 누락을 TSMC PR에 그대로 복사하지 않습니다. 별표가 있는 값은 계속 부분 모델입니다.
- 민감도 표와 설정 비교도 최악/평균을 구분합니다. 말일 지수와 기간 평균 병목을 함께 제공합니다. 카드의 종합 병목은 ‘최악 기업’ 기준이라고 명시했습니다.
- 지원 범위는 4개 기업 모델이며 SK하이닉스·인텔·마이크론 등은 미포함이라고 표시했습니다. 개별 실제 팹의 가동률로 부르지 않습니다.

## 확인한 결과

| 시나리오 | 기업별 결과 | 집계/해석 |
|---|---|---|
| TSMC 공급 중단 30일 | 전공정에서 삼성 100, TSMC 0 | 최악 0, 공정별 기업 단순평균 50. 패키징은 ASE/Amkor의 100*이며 삼성/TSMC 칸은 미등록 |
| 삼성 공급 감소 50% 30일 | 삼성 50, TSMC 100 | 최악 50, 기업 평균 75 |
| 삼성·TSMC 동시 75% 감소 | 각각 25 | 최악·평균 모두 25 |
| ASE 공급 중단 30일 | 패키징 ASE 0, Amkor 100 | 패키징 평균 50. 전공정 평균은 100 유지 |
| 대만 전체 공급 중단 30일 | 삼성 100, TSMC 0, ASE 0, Amkor 100 | 전공정과 패키징 평균 각각 50. 현재 등록된 국가 전체 이슈 가정이며 실제 국가 생산량 예측이 아님 |
| TSMC 3일 중단 + 관측 60일 | 삼성 100 유지, TSMC 1~3일 0/4일부터 100 | 평균 곡선 1~3일 50/4일부터 100, 말일 평균 100, 기간 평균 병목은 최악 95/기업 평균 97.5 |

표의 수치는 가정 모델 값입니다. 해당 공정/기업에 누락 제약이 있으면 화면에 *가 붙습니다. ‘삼성 100*’도 실제 공급이나 가동률이 100이라는 증거가 아닙니다.

두 병목 지수는 각각 해당 집계의 등록 공정 중 최솟값입니다. 기업 평균 병목 50은 8개 공정 평균이나 산업 생산량 50%가 아닙니다.
