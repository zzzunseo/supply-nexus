# 핵심 지적 1번 수정·검증 보고

2026-10-26 · 근거 없는 관계가 공급량으로 들어가던 문제부터 수정했습니다. 다른 핵심 지적을 모두 해결했다는 보고가 아닙니다.

## 바뀐 계산 범위

원본 44개는 보존하고 30개만 공급 계산에 사용합니다. 비공급 관계 9개와 과거 공급 기록 5개, 총 14개는 참고 표시만 합니다. `supply` + 허용 시점(`documented`, `scope_limited`) + 공급 관계 출처를 모두 만족해야 계산용 route가 생깁니다. 미분류·누락은 허용하지 않습니다.

따라서 TOK→삼성 미확인 관계, 삼성→ASE의 만료된 인증 관계, TSMC→Amkor 예정 계약은 모두 제외됩니다. Merck→삼성 서비스 관계는 제외하되 같은 제품의 Merck→TSMC 공급 관계는 유지합니다.

- 제외 관계는 혼합 투입재·물류 경유·도착지 재고·그 고객에 대한 우회 경로로 재유입되지 않습니다.
- 제품이 참고 관계에만 연결되어 있으면 대체 예약 풀을 요청하지 않습니다.
- 지도에서는 회색 점선이며 공급률을 붙이지 않습니다. 같은 좌표의 공장/기업 상태를 중단으로 바꾸는 집계에도 참고 전용 제품을 쓰지 않습니다.
- 남은 공급사는 기존 혼합식으로 정규화합니다. 실제 점유율을 만들어 넣지는 않았습니다.

## 누락 데이터의 표시

필터 뒤에 계산 경로가 없는 필수 품목 그룹 10개를 발견했습니다. 삼성 PR, ASE/Amkor 가공 웨이퍼 등이 포함되며 하위 의존성을 포함해 8개 중 6개 공정의 범위가 불완전합니다.

이 값을 정상 공급 100%로 단정하지 않도록 전체 지수를 **부분 모델 병목 지수**로 부르고, 해당 공정·곡선에 `*`를 붙였습니다. 설정에는 계산 포함/제외 사유와 누락 품목 표를 추가했습니다. 비교 다운로드에도 범위·누락 공정을 넣었습니다. 결과 카드에서 기업 중단으로 지수가 0인데도 100%라고 표시되던 기존 대체 문구도 실제 결과 값으로 고쳤습니다.

`100*`는 누락된 투입재가 정상이라는 뜻이 아닙니다. 남은 제약만 계산한 조건부 값입니다. `*`가 없는 공정 역시 실제 계약·물량이 모두 확인됐다는 뜻은 아닙니다.

## 결과 변화의 이유

실리콘 + 주석 솔더 레시피, 이슈와 관측 기간 동일, 재고·우회 켬 조건으로 수정 전 모델과 비교했습니다. 아래 수정 후 값은 모두 부분 모델 범위입니다.

| 이슈 | 수정 전 전체 → 수정 후 | 패키징 변화 | 이유 |
|---|---|---|---|
| 일본 PR 30일 | 60 → 60* | 100 → 100* | TSMC 공급 경로는 남음. 삼성 PR과 패키징 입력에는 누락 표시 |
| TSMC 중단 30일 | 0 → 0* | 50 → 100* | 근거 없는 가공 웨이퍼 4개 경로가 패키징 계산에서 빠짐. 정상화가 아님 |
| 독일 NF3 60일 | 70 → 70* | 70 → 100* | NF3 레시피 활성화. 검증되지 않은 가공 웨이퍼 전달 효과가 빠짐 |
| 말라카 봉쇄 30일 | 0 → 0* | 0 → 0* | 주석 솔더 등 남아 있는 가정 경로의 물류 제약은 유지 |
| 미국 석영 중단 60일 | 0 → 0* | 0 → 100* | 근거 없는 가공 웨이퍼 경유로 패키징까지 전파하던 계산 제거 |

재고·우회 민감도도 같은 원본 엔진으로 다시 계산합니다. 기존 PR30 테스트의 ‘우회 한도 절반이면 반드시 전체 30’이라는 값은 제외된 고객과 물류 단계의 예약 풀 수요가 바뀌어 그대로 유지되지 않았습니다. 임의로 60을 새 기대값으로 고정하지 않고, 입력을 직접 절반으로 바꾼 엔진 계산과 일치하는지 검사하도록 바꿨습니다. 별도 단일 단계 모델에서는 60→30→90의 한도 변화도 검증했습니다. 제품 단계와 배송 단계의 우회 한도 해석은 3번 항목에서 추가 검토해야 합니다.

## 검증

- 전체 Python unittest: **137개 통과**. 새 회귀 검사 **13개** 추가.
- JavaScript: **17개 통과**, legacy 코드는 변경하지 않았습니다.
- AppTest: 기본 로딩·설정창·기존 기간 관리·새 범위 경고·참고 전용 품목 입력에서 예외 0개.
- 제외 관계 전부에 계산 route와 물류 경유가 없는지 검사.
- 남은 공급사 정규화: 산소 공급 2곳 중 한 관계를 제외하고 남은 공급사를 중단했을 때 50%가 아니라 0%가 되는지 검사.
- 같은 Merck 제품의 삼성 경로 제외/TSMC 경로 유지를 함께 검사.
- 참고 전용 제품의 예약 풀 소비와 시설 색상 오염이 없는지 검사.
- 국외 항구를 지나는 유효 우회 경로가 참고 관계로 빠진 고객에게 잘못 그려지지 않고, 개방된 항구 통과만으로 파란 우회 표시를 잃지 않는지 검사.
- 실제 브라우저: 원본 표 3페이지에서 JSR 연구·TOK 미확인 삼성 경로 제외/TSMC 공급 포함, 6페이지에서 패키징 네 참고 관계 제외 확인.
- 실제 브라우저: 삼성 가공 웨이퍼 중단 입력 시 참고 전용이라는 안내, 공급 지수 100* 유지, 삼성 거점 정상 표시 확인. PR30과 TSMC30에서도 별표·부분 모델 문구·회색 참고 선 확인.
- 원본 데이터 JSON 7개는 SHA256 동일. `share_pct=null`, `model_share_pct` 가정 구분 유지.
- 엔진의 재고·min/가중합·예약 풀 배분 계산식은 변경하지 않았습니다. 반환값에 누락 범위 메타데이터 2개만 추가했습니다.

기존 검사는 삭제하지 않았습니다. 석영 피해가 패키징까지 전파된다는 기대 1개, 실제 그래프의 민감도 직접 비교, 타임라인의 별표 이름 기대를 요구사항에 맞게 수정했습니다.

## 남은 지적

다음 순서는 팹별 점수와 최악/평균 집계입니다. 대체 인증·확대 기간, 공급사 조사 범위/SPOF, 장비 별도 모델, 별칭, 대체 항로/항공 운송은 아직 완료하지 않았습니다. 현재 30개 계산 포함도 실제 현행 품목 납품 계약을 새로 검증했다는 의미가 아닙니다. 외부 API는 호출하지 않았습니다.
