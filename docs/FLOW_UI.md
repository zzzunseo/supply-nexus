# 2단계: 공급 흐름 SVG 화면

1단계 파일은 메인 프로젝트에 통합되어 있으며 `flow_data.build_flow`를 그대로 사용한다.
계산 엔진과 원본 데이터는 수정하지 않는다.

## 화면 구성

- 기본 공정은 포토이며 설치된 Streamlit 1.66.1의 `st.pills` 8개로 공정을 선택한다.
- 지구본을 기본 화면의 중심으로 크게 표시한다.
- 공급 흐름은 기본적으로 접어 두고, 아래 **공급 흐름 · 펼쳐보기**를 열어서 본다.
- 지도는 전체 활성 공급망의 연결선과 주요 기업·시설명을 기본 표시한다.
  정상 경로는 청록색, 차질은 붉은/주황 점선, 우회는 굵은 파란 선으로 구분한다.
  선에는 약한 빛 번짐, 차질 지점에는 바깥 고리를 표시한다.
  실제 계산 결과에서 활성인 우회 경로는 파란 점선이 이동한다. 실제 선박 추적은 아니다.
  동작 줄이기 설정을 사용하는 화면에서는 이동 효과를 끈다.
  상세 이름과 근거는 기존 hover에도 유지한다.
- 기존 지도 선택으로 기업이 선택되면 그 기업 이름과 대표 시설명을 고정 표시한다.
- 흐름은 지구본 아래 고정된 4열(공급 기업 → 소재 → 공정 → 영향 기업)로 표시한다.
- 서버가 SVG 한 장을 생성한다. Streamlit의 SVG 태그 제거를 피하기 위해 생성한 SVG를
  데이터 이미지로 전달한다. 카드에 링크나 클릭 동작은 없다.
- 기업은 사각형, 소재는 둥근 사각형, 공정은 육각형이며 종류 라벨을 함께 표시한다.
- 상태는 기호·문자·감소율을 함께 사용한다. 계산 결과 누락은 미확인, 제외는 계산 제외로 표시한다.
- 이름은 생략하지 않고 줄바꿈한다. 길이에 맞춰 카드 높이가 늘어난다.
- 공급 기업과 그 기업 제품의 행 순서를 맞춘다. 카드가 많으면 흐름 영역 내부에서 스크롤한다.
- 100vh 바깥 페이지 스크롤을 늘리지 않는다. 좁은 흐름 영역은 내부 가로 스크롤을 사용한다.
- 기존 일별 공급 충족도 그래프는 아래 **타임라인**을 펼쳐서 본다.

## 검증

`tests/test_flow_contract.py`의 보강 검사 8개는 8공정×2시나리오, 모든 끝점,
영향 기업 열이 비는 경우, ID 안정성, 입력 순서에 무관한 정렬, 입력 불변성,
식각 제외 연결 3개와 원본 제외 관계 3개를 검사한다.

`tests/test_flow_ui.py`의 8개 검사는 SVG 구조와 이름 보존, 행 겹침, 종류별 모양,
비클릭 카드, 빈 화면, 문자열 이스케이프, 위치 전용 지도, 선택 기업 전체 이름,
공정 전환 때 계산 불변성, 지정 시나리오의 AppTest 예외 0개를 검사한다.

브라우저 직접 확인 결과와 스크린샷은 현재 작업의 `flow-step2-report.md`에 기록한다.
3단계 선택 경로 강조와 4단계 재고·우회·근거 배지는 이번 단계 범위에 포함하지 않는다.


## 선택 경로 강조
기업·소재 찾기는 현재 공정 소재와 기업을 제공한다. 선택한 대상이 다른 공정에 있으면 선택을 유지하고 해당 공정에 없다는 문구를 표시한다.
공급 이전과 이후는 각각 방향을 따라 탐색하며, 공유 공정의 무관한 공급사로 되돌아가지 않는다. 카드·화살표는 굵기와 밝기로 강조하고 카드에 클릭 동작을 추가하지 않는다.
지구본 점 선택은 별도의 Streamlit v2 클릭 전달부로 공유 rr_focus 상태를 갱신한다. 5px 초과 드래그와 현재 선택 재클릭은 갱신하지 않으며, 연결선과 빈 영역은 선택하지 않는다. 이벤트 처리 후 추가 st.rerun을 호출하지 않는다.
지구본 클릭 전달부는 Plotly SVG 점의 데이터 연결을 사용하므로 Plotly 구조 변경 시 클릭 회귀 검증이 필요하다. 현재 클릭 전달부의 최종 브라우저 동작은 미확인이다.


## 근거 표시
소재 카드의 evidence는 해당 result_node_id의 결과만 복사한다. stock_remaining은 남은 재고의 일수 환산량이며, 설정 inventory_days를 현재 재고로 대체하지 않는다. backup은 마지막 관측일의 소재 자체 대체공급 비율이다. 항만 우회 운송량이나 설정상 우회 한도와 합산하지 않는다.
재고 소진일·미소진 날짜·소진일 미확인 표시와 소재별 소진 기록은 제공하지 않는다. 기업 내부 재고 자료가 없으므로 실제 소진일을 예측하지 않는다. 남은 재고와 우회 활성은 모델 수치이며 화면에 가정 재고·모델 우회로 표시한다. 공정 first_hit을 소재 날짜로 바꾸지 않는다. 누락·비정상·제외 값도 0으로 대체하지 않는다.
계산 제외 연결은 점선과 제외 배지, 가정 점유율 연결은 가정 배지로 표시하며 둘 다 해당하면 배지 둘을 표시한다. 연결 수에 따라 카드 높이와 시작점을 배분해 배지를 분리한다. 화면은 스크롤하며 모든 이름을 유지한다.
