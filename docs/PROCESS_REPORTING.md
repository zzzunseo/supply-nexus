# 기업별 공정 및 최악/평균 집계 계약

## 모델 범위

현재 출력 모델은 삼성전자·TSMC의 전공정 7개와 ASE·Amkor의 패키징입니다. 이는 기업 수준의 가정 모델이며 실제 개별 팹의 가동률이 아닙니다. SK하이닉스·인텔·마이크론 등으로 일반화하지 않습니다. 소재·공급사 후보와 공정 출력 모델의 대상은 다릅니다.

미등록 기업×공정은 None으로 남깁니다. 화면에서는 ‘— 미등록’이며 0%나 100%로 보간하지 않습니다. 평균의 분모에도 넣지 않습니다.

## 집계

공정 p에 등록된 기업 집합을 C_p라 하고, 날짜 t의 기업별 계산 충족도를 s(c,p,t)라 합니다.

- 최악 기업: min(s(c,p,t), c in C_p).
- 기업 단순평균: sum(s(c,p,t), c in C_p) / len(C_p).
- 각 보기의 말일 병목 지수: 그 보기에서 등록된 공정별 말일 점수 중 최솟값.
- 각 공정의 기간 평균: 해당 공정의 일별 점수를 관측 일수로 나눈 시간 평균.
- 민감도 표의 기간 평균 병목: 각 날짜의 공정 최솟값을 구한 뒤 그 일별 병목을 시간 평균.

기업 평균은 생산량·매출·시장점유율 가중평균이 아닙니다. 입력재의 기존 병렬 공급 비중과도 다른 개념입니다. 전공정 평균에는 삼성·TSMC만, 패키징 평균에는 ASE·Amkor만 들어갑니다. 4개 기업을 모든 공정의 분모로 쓰지 않습니다.

## 반환값

기존 `scores`, `overall`, `timeline`, `first_hit`, `average_scores`는 최악 기업 집계를 그대로 유지합니다.

새 `process_views`는 `worst`, `mean`, 등록 기업 ID(`samsung`, `tsmc`, `amkor`, `ase`)별로 다음 필드를 제공합니다.

- scores / overall / timeline / first_hit / average_scores
- registered_processes: 해당 보기의 등록 공정 목록
- incomplete_processes: 해당 기업에 실제로 연결된 누락 제약의 전파 범위. 집계 보기는 그 공정 참여 기업의 누락 범위를 합칩니다.

`company_names`, `company_processes`, `aggregation_note`도 제공합니다. 이름·기간·선택 소재·활성 이슈와 함께 결과 저장 파일에 들어갑니다. 미등록 값은 JSON null로 유지합니다.

기존 `average_scores`는 기업 평균을 뜻하지 않고 ‘최악 집계의 시간 평균’입니다. 기업 평균의 시간 평균은 `process_views['mean']['average_scores']`입니다.

## 표시와 해석

- 왼쪽은 최악 기업/기업 단순평균을 나란히 표시합니다. 막대는 최악 집계입니다.
- 전공정 7개에서 삼성·TSMC의 등록 공정 병목을 따로 표시합니다.
- 지구본 위 네 번째 선택 상자는 타임라인 보기만 바꿉니다. 지도나 시뮬레이션 조건, 왼쪽 두 집계는 바꾸지 않습니다.
- ‘기업별 공정 점수·모델 범위’에서 기업별 표, 등록 기업 수, 기업별 누락 제약을 확인하고 일별 결과를 저장합니다.
- 민감도는 최악/기업평균 각각의 말일과 기간 평균을 표시합니다. 원인 카드는 개별 소재 또는 최악 집계를 기준으로 표시합니다.
- 별표는 누락된 필수 투입재 제약이 있는 부분 모델입니다. 100*는 정상 보장이 아니고, 별표가 없는 공정도 실제 계약·물량의 완전한 검증을 의미하지 않습니다.

## 기존 계산과 분리

`ProcessReporter`는 하루 계산이 끝난 `daily`와 기존 공정 점수를 읽기만 합니다. 재고 소비, 원래 공급 비중, 필수재 min, 공유 예약 풀 배분, 인증/확대 기간 계산에는 쓰지 않습니다. 이슈 days와 관측 기간 분리도 유지합니다.
