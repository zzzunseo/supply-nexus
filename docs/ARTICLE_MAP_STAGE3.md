# 3단계 — 기사 관련 등록 경로 지도

2026-10-27. 실행 주소: http://localhost:8517/ (8520도 동일 소스).

## 시연 흐름
1. ‘기사 붙여넣기 · 원문 검토’에서 본문을 넣고 대상을 검토합니다.
2. 검토 결과를 저장한 뒤 오른쪽의 ‘기사 관련 경로 지도 보기’를 누릅니다.
3. 지도 경로 중앙의 번호 있는 ◇ 선택점 또는 상단 경로 목록에서 선택합니다.
4. 오른쪽에서 해당 경로의 연결 이유·관련 공정·출처를 확인합니다. ‘등록 위치 근거’와 ‘기사 원문 근거’도 펼쳐볼 수 있습니다.

## 구현한 구분
- 공급관계 근거: 청록 실선. 기업 간 관계 출처이며, 특정 품목의 현행 계약·물량·기사상 고객 피해를 확인한 뜻이 아닙니다.
- 참고 관계: 회색 점선. 협업·과거 등 계산에서 제외한 관계를 공급 계약으로 바꾸지 않습니다.
- 추가 경로 가정: 보라색 파선. 실제 납품이 확인된 관계로 표시하지 않습니다.
- 선택한 경로는 더 굵게, 다른 경로는 흐리게 표시합니다. 선택점과 목록은 동기화됩니다.
- 관련 기업이 가까이 모여 있으면 해당 지역을 확대해 선택점과 이름을 읽기 쉽게 합니다. 원래 등록 좌표를 변경하지 않습니다.

지도는 기사 전용 별도 창입니다. 기존 시나리오 지도·점수·사건·계산 범위·선택 상태를 변경하지 않으며 계산 결과를 지도 생성에 사용하지 않습니다. 기사 때문에 빨간 피해 표시나 감소율을 만들지 않습니다.

## 위치와 범위의 한계
등록된 기업/사업장의 좌표 출처가 있을 때만 선을 표시합니다. 본사도 포함되므로 기사 속 사고 공장이나 실제 운송 경로로 해석하면 안 됩니다. 본문에 시설명이 있어도 자동으로 그 회사 본사 좌표와 결합하지 않습니다. 위치가 없거나 양 끝 좌표가 같으면 선을 만들어내지 않고 목록에서 누락 이유를 보여줍니다. 현재 데이터에서 경로 ID를 찾지 못한 경우도 미표시로 알립니다.

기업을 대상으로 선택하면 그 기업의 등록 관련 관계를 보여주고, 구체적인 소재 후보를 선택하면 해당 소재의 등록 관계로 범위를 좁힙니다. 제품 등급·특정 시설별 현행 계약까지 확정한 분석은 아닙니다. 등록 경로와 현실의 피해는 별도입니다.

선 전체의 임의 지점 클릭이 아니라, 경로 중앙의 명시적인 ◇ 선택점 클릭으로 근거를 연결합니다. 목록 선택도 같은 동작을 제공해 시연 중 선택이 어렵더라도 사용할 수 있습니다.

## 검증
관련 Python 24개(기사 지도 7개, 기존 원문 검토 10개, 기사 구조화 7개) 통과. 기사 지도 7개는 최종 확대 배치 변경 뒤 다시 통과했습니다. 지도 선택 브리지의 신규 JavaScript 4개와 기존 지도 클릭 4개도 통과했습니다. 무관한 전체 검증은 반복하지 않았습니다.

대상 경로만 표시, 근거 구분, 출처를 현재 등록 데이터에서 조회, 좌표 미등록/잘못된 위치 소속/사라진 경로 처리, 본사와 사건 장소 구분, 입력 그래프 비변경, 시나리오 결과·범위·선택 비변경을 확인했습니다.

실제 브라우저에서 가상 기사 입력 → 검토 저장 → 기사 지도 열기 → 지도 ◇ 선택점 클릭 → TSMC 경로 선택 및 출처 표시 → 목록에서 삼성 참고 경로 선택 및 참고 사유 표시까지 확인했습니다. 최종 화면에는 등록된 JSR 본사가 등장하며 사고 장소 표시가 아닙니다. 실제 기사나 피해 사례를 확인한 화면이 아닙니다.
