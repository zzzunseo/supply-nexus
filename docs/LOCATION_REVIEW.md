# 공급망 지도 위치 점검 결과

2026-10-26 · 등록 위치 27곳 재점검 · 기존 연결 44개 보존

사업장·건물 좌표 근거 23건과 공식 지도 POI 4건을 다시 조회했습니다. 기존 22건은 OSM 도형 범위와 일치했고, 공식 POI 4건은 등록 좌표와 일치했습니다. Applied Materials 1건은 도로 참조 오류를 교정했습니다. 도형 범위 일치는 개별 생산 라인이나 시설 간 계약의 증명이 아닙니다.

## 반영 사항

- Applied Materials: 기존 Bowers Avenue 도로 링크와 주소 보간점 대신 Bowers 사업장의 OSM Building 1 도형 대표점(37.37760875, -121.97876855)으로 교정. 특정 제조·출하동으로 단정하지 않음.
- SUMCO: 열리지 않던 인증서 링크 대신 공식 사업장 목록과 구바라 공장 인증서로 주소·역할 출처 보완.
- Merck·Air Products·WACKER·ASE: 주소·사업장 역할을 확인할 수 있는 공식 자료로 근거 보완.
- POSCO: 광양제철소 전체 부지 대표점임을 명시. 동호안 희귀가스 공장 건물의 정확한 좌표로 해석하지 않음.
- TSMC Fab 18: 캠퍼스 위치로 표기. Fab 18A/18B 생산동별 좌표로 구분하지 않음.
- 지도: 본사 16곳은 빈 사각형, 시설은 원형, 참고 팹은 빈 원형. 색상은 기업·소재 모델 상태이며 시설 가동률이 아님.
- 모든 선에 실제 시설 간 운송·납품 경로 미확인 표시. 앱 설정에 전체 위치 점검표 및 저장 기능 추가.

## 검증 및 남은 범위

전체 Python 검사 87개와 메인 화면·설정창 실행 검사를 통과했습니다. 웨이퍼 제조·식각 필터의 실제 시설 표시, 본사 기호, 44개 연결 보존, 다른 기업 시설의 잘못된 연결 차단을 확인했습니다.

Stella Chemifa, Stella Chemifa Singapore, TEMC, SK materials 계열, 5N Plus St. George는 이번 작업에서 신규 좌표를 추가하지 않았습니다. 위치 근거 미확인 항목은 계산에 유지하고 지도에서 숨깁니다. 국가 수준 원료에도 임의 광산 점을 추가하지 않았습니다.

현재 등록된 본사 위치는 기업 관계를 보여주는 기준점입니다. 특정 품목의 실제 생산·출하 공장으로 교체하려면 해당 품목과 사업장의 역할 근거를 추가로 확인해야 합니다.
