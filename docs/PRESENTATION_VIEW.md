# 발표 보기 구현 기록 · 2026-10-25

지구본 위의 ‘전체 공급망 · 발표 보기’로 켜고 끕니다. ‘대표 장면 · 네덜란드 50% 감소’는 포토 공정, 14일, 공급 능력 50% 감소, 재고 적용, 대체 미적용을 설정합니다. 계산 완료 후 실제 엔진 결과를 표시합니다.

- 원본 기업 경로 44개를 한 번에 표시합니다. 다른 공정은 옅은 파랑, 선택 공정은 시안, 감소·중단은 주황·빨강입니다. 화면 밖 지구 반대편 경로는 회전하여 볼 수 있습니다.
- 소재별 흐름 안내를 누르면 해당 소재의 상세 연쇄로 이동합니다.
- 일반 소재 연쇄는 소재별 경로 묶음으로 페이지를 구성하고, 해당 페이지의 경로에 연결된 노드만 표시합니다. 현재 데이터는 페이지당 최대 15개를 유지합니다.
- 기존 계산식, 데이터 근거, 배분 가정, 3열 화면 구조는 유지했습니다.
- 발표 보기는 기업 관계·협력·과거/예정 계약을 포함한 후보망입니다. 실제 물류나 검증 완료된 품목 납품망으로 해석하면 안 됩니다.
