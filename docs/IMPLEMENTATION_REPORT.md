- 기업 경로를 Python 병목 모델에 입력. 기존 engine.py 수식과 requires는 수정하지 않음.
- 국가 화면은 동일 공정·소재의 기업 경로를 국가별로 합산. 기업 계산 결과와 계산용 배분율을 사용해 가중 표시.
- 같은 국가의 여러 core 기업은 국가 묶음으로 표시. 클릭 또는 카메라 확대 시 국가 점 주변의 겹치지 않는 좌표로 펼침.
- 소재 연쇄는 소재 → 공급 기업 → 수요 기업 → 공정 표시점. 파생 노드·표시 연결은 계산에 포함하지 않음.
- 한 번에 최대 15개 호. 초과분은 더 보기로 다음 페이지, 마지막은 처음 보기로 순환.
- 라벨 최대 국가 8 / 기업 10 / 연쇄 12개. 화면 좌표로 충돌을 검사해 중단 > 감소 > 선택 공정 > 기타 우선 표시, 같은 우선순위에서는 포커스 우선.

- 오른쪽 연계 기업·소재 목록: 소재 칩 → 공급 기업 → 소속 국가. 소재·기업 클릭은 지도와 동일한 포커스.
- 기업/품목 공식 자료, 실제 관계 미확인, 계산 가정의 배지를 구분. 실제 배분율과 가정 배분율을 별도 표기.
- 계산 JSON의 공급 배분에도 source/source_year/status/share_basis를 기록. 다운로드에는 기업·소재·관계 원본 근거도 포함.
- 데이터 파일 변경 시 Streamlit 캐시 갱신. 프런트엔드는 빌드된 로컬 번들 사용.

## 남은 문제와 다음 라운드 경계

1. 실제 거래·배분율을 확인하기 전까지 결과는 가정 기반입니다. 실제 share_pct를 입력해도 계산 가정이 자동 승격되지는 않습니다. 근거 확인 후 model_share_pct/계산 입력을 함께 검토해야 합니다.
2. 소속 국가의 회사 이름으로 묶었으므로 실제 생산 시설 소재국의 공급 위험을 보여주는 모델은 아닙니다.
3. EDS·패키징·이온주입·웨이퍼 제조의 상세 투입재와 공정 경계는 보완해야 합니다. 현재 core는 업계 전체를 대표하는 검증된 순위가 아닙니다.
4. 국가별 숫자는 같은 공정·소재의 경로 배분 합계입니다. 물량·금액·설비 생산 능력 합계는 구현하지 않았습니다.
5. 표시 노드의 상류·하류 탐색은 UI 기능입니다. 노드 requires, 다단계 의존성 계산, 시간별 재고 소진·실제 물류 우회는 다음 라운드 범위입니다.
6. 데이터 편집·신뢰도 승인 화면은 없으며 JSON을 수정합니다. source_year가 없는 자료는 원문 기준연도 확인이 필요합니다.
7. 작은 화면에서는 라벨이 더 많이 숨겨집니다. 숨겨진 기업·소재는 오른쪽 목록에서 선택할 수 있습니다. 모든 브라우저·기기에서의 실측 가독성 조정은 남아 있습니다.
