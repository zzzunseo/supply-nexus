## 적용 내용과 변경 파일

상세 경로와 원문 링크는 **DATA_REVIEW.md**, 전체 출처 원장은 **data/evidence.json**입니다.
공식 1차 자료 **49건**의 링크·확인 내용·자료 연도·주장 범위를 원장에 기록했습니다.

이번 변경은 데이터 근거와 그 범위를 보여주는 UI에 적용했습니다. 43개는 공급·연구·서비스·인증·예정 계약을 합친 수이며, 세부 품목의 현재 납품 검증 수와 다릅니다.
기업 관계의 근거 배지, 품목 근거, 과거·예정 상태, 본사 국가 출처를 각각 표시합니다. 연도가 없는 공식 페이지는 확인 날짜와 함께 연도 미표기로 표시합니다.
실제 구매 배분율과 재고·대체 여력은 가정값을 실제 수치로 승격하지 않았습니다.

변경 파일:

- app.py: 근거 원장 변경도 캐시 갱신에 반영.
- data/demo.json: 기업 주소 근거·43개 관계의 범위·9개 품목 근거·시점·CF4·공시 참고 지표.
- data/simulation_demo.json: CF4 명칭 일치. 계산 수치 유지.
- data/evidence.json: 공식 1차 근거 원장과 배제한 추론.
- data_loader.py: 근거 ID 및 기업/품목별 출처 검증.
- frontend/index.js: 범위별 배지·원문·국가 근거·검증 요약·공시 참고 수치.
- frontend/view-model.mjs: 국가 합산 시 근거 ID·품목 상태 보존.
- frontend/dist/globe-ui.js: 빌드 번들.
- tests/test_research_evidence.py, tests/fixtures/pre_research_scores.json: 근거 범위와 기존 점수 보존 검사.
- tests/test_linked_data.py, tests/linked-view.test.mjs: 관계 상태와 비중 상태를 구분하도록 갱신.
- README.md, MODEL.md, DATA_REVIEW.md, IMPLEMENTATION_REPORT.md, CHECKS.md: 현재 근거 범위·한계 문서.

남은 핵심은 특정 고객·품목·등급·시설·연도별 실제 납품과 비중입니다. 실제 생산 시설 지도, 조달 계약 원문, 재고 실측을 확보해야 이 시연 모델을 실증 모델로 발전시킬 수 있습니다.
