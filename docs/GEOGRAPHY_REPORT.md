# 지도 위치 교정 · 2026-10-26

이전 지도에서 바다 위에 있던 `식각`, `웨이퍼 제조` 등 8개 공정 점은 점수 비교용 가상 표시점이었습니다.
공정은 시설이 아니므로 해당 점·연결선을 지도에서 제거했습니다. 공정 점수는 좌측과 계산 결과에 유지합니다.
소재·기업 점의 겹침을 피하려고 위도·경도를 옮기던 코드도 제거했습니다.

## 현재 표시 기준

- `data/verified_locations.json`에 **27개** 건물·캠퍼스·사업장을 등록했습니다. 공식 시설/주소 자료와 기업이 연결한 지도 POI 또는
  OpenStreetMap 건물/캠퍼스 도형을 대조했습니다. 세부 좌표와 각각의 원문 URL을 기록했습니다.
- 원본 17개 기업은 모두 확인된 사업장에 연결했고 원본 경로 44개를 보존합니다. 단, 본사·사업장을 경로의 기업 대표 위치로 쓰는 것은
  실제 운송 출발지·도착지나 시설별 계약이 확인됐다는 뜻이 아닙니다. 지도와 자료 창에서 본사·팹·웨이퍼 공장을 구분합니다.
- 추가 기업/거점은 13개 중 8개의 위치를 연결했습니다. Stella Chemifa, Stella Chemifa Singapore, TEMC, SK materials 계열,
  5N Plus St. George는 이번에 좌표와 주소를 충분히 대조하지 못해 지도에서 제외했습니다. 이들의 데이터·공정 계산은 유지합니다.
- 미국 고순도 석영은 실제 Sibelco Quartz Site에 연결합니다. 국가 수준 원산지 자료만 있는 중국 세륨·갈륨·게르마늄, 우크라이나 네온,
  러시아 팔라듐 등을 특정 광산/공장 좌표로 바꾸지 않습니다. 해당 국가 중심에도 임의의 광산 점을 찍지 않습니다.
- 소재·대체 예약풀은 관련 사업장 좌표를 그대로 공유합니다. 같은 위치는 점 하나에 묶고, 원래의 개별 항목·상태는 보존합니다.
- 국가 집계 대표점도 실제 등록된 사업장 한 곳을 사용하며 평균 위경도로 바다 위 점을 만들지 않습니다.

식각은 칩 가공 팹의 공정이므로 삼성 기흥·평택과 TSMC 팹 위치에서 관련 사업장을 보여줍니다.
각 식각 장비가 있는 건물·층·생산 라인의 위치를 확인한 것은 아닙니다. 참고 팹에 임의의 공급 물량 비중을 배정하지 않았습니다.
웨이퍼 제조는 실리콘 기판 생산을 뜻하며, 위 두 일본 웨이퍼 공장과 칩 가공 팹을 같은 종류로 취급하지 않습니다.

## 사용 방법

1. 메인 http://127.0.0.1:8517/ 을 새로고침합니다.
2. 공정 필터를 `웨이퍼 제조` 또는 `식각`으로 바꿉니다. 점의 이름은 실제 사업장명입니다.
3. 점에 마우스를 올리면 시설 종류·주소·좌표 정밀도·모델 공급 충족도를 봅니다.
4. `소재·44개 경로·가정 설정 → 실제 위치·근거`에서 위치별 주소 원문과 지도 링크를 확인합니다.

좌표 정밀도는 기업 지도 POI 또는 건물·캠퍼스 도형 중심입니다. 복수 생산동이 있는 캠퍼스의 경우 실제 장비 위치까지의 정밀도가 아닙니다.
본사에 있는 가스·장비 회사의 점은 해당 회사의 실제 공장 생산 좌표로 사용하지 않습니다.
시설별 생산/조달 비중은 전부 미확인이므로, 위치가 확인됐다는 이유만으로 지역 피해를 기업 전체의 공급 중단으로 자동 환산하지 않습니다.

국가 평균점 제거, 웨이퍼/식각 필터의 실제 시설, 위치 미확인 숨김을 확인합니다.
