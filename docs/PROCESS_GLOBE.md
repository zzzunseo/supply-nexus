# 지구본 공정별 연결 보기

지구본 위의 `전체 / 웨이퍼 제조 / 산화 / 포토 / 식각 / 증착·이온주입 / 금속배선 / EDS / 패키징`에서 보고 싶은 공정을 선택합니다. 선택한 공정의 공급 입력과 상위 소재만 연결하고 이전 공정 전체를 펼쳐서 혼합하지 않습니다.

상단에서 공정을 바꾸면 아래 공급 흐름 카드도 같은 공정으로 바뀝니다. 아래 카드의 공정 버튼을 누르면 지구본도 따라 바뀝니다. `전체`를 선택하면 지구본은 기존 전체 공정망으로 돌아가며, 상세 카드는 마지막에 선택했던 개별 공정을 유지합니다. 펼치기 제목에 그 공정 이름을 표시합니다.

기업·소재를 선택하면 관련 경로를 강조합니다. 다른 공정으로 전환했을 때 기존 선택 대상이 해당 공정에 없으면 선택을 해제합니다. 선택 상자의 후보도 현재 공정 범위에 맞춰 줄어듭니다. 해당 경로에 속한 항만·해협과 활성 우회 경유점 선택은 유지합니다.

지구본은 위치 근거가 있는 점과 경로를 표시합니다. 위치가 없는 공급사를 임의의 국가 중심점에 찍지 않으며, 해당 업체 수를 지도 아래에 안내합니다. 자세한 기업·소재 이름은 공급 흐름을 펼쳐 확인합니다. 추가 소재는 현재 계산 시나리오에서 활성화된 범위만 표시합니다.

정상 경로, 차질의 붉은 점선, 활성 우회의 파란 선, 계산 제외의 참고 점선을 유지합니다. 대체 예약풀이 등록됐다는 이유로 아직 활성화되지 않은 우회 운송을 생성하지 않습니다. 회사의 지도 표시 상태는 선택 공정의 기존 계산 결과를 사용합니다. 다른 공정에서 발생한 차질만으로 현재 선택 공정의 회사 점을 빨갛게 만들지 않습니다.

엔진 계산식·기업별 공정 점수·시나리오 입력은 이 화면 선택으로 바뀌지 않습니다. 지구본을 크게 보고 공급 흐름을 필요할 때 펼치는 기존 배치를 유지합니다.
