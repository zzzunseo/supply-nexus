# AI 시나리오 검증 (2026-10-30)

## 수정 범위
- 공정·대체 공급사·항로가 섞인 질문은 통합 검토로 분류해 요청한 결과가 누락되지 않도록 수정.
- 관세 시행 확인과 가정한 영향을 구분하고 정부·세관의 품목·원산지·시행일 근거를 요구.
- 공장 사건과 해당 시설의 제품·등급·공정 근거를 구분하는 조사 계획 추가.
- 질문 예시를 바꾸면 검토 범위와 질문 목적을 자동으로 초기화.
- 출처 미제공, URL 검사 제외, 최종 답변 누락을 구분. 검색 결과가 부족한 경우 성공으로 표시하지 않음.
- 실제 평가 화면에서 실패한 검색의 진단도 보존.

## 자동 시나리오
| 종류 | 질문 범위 | 확인 내용 |
|---|---|---|
| 관세 | 희토류 공정 영향, 산화세륨 관세와 대안 | 공정/통합 분류, 정책 근거 조사 계획 |
| 기업 | SUMCO 공급 중단, Soitec SOI | 대체/통합 분류, 원래 질문 보존 |
| 소재 | HF, NF3, ArF, 금·구리 와이어 | 제품 조건 비교 범위, 검색 인용 처리 |
| 공장 | TSMC Fab 14, 효성 용연 NF3 | 시설 근거 조사 계획 |
| 물류 | 말라카, 관세와 수에즈 복합 질문 | 항로/통합 분류 |

12개 질문에 모의 API 응답을 적용해 요청 구성·결과 파싱을 검사합니다. 답변의 사실 정확성이나 실제 API 성공을 검증하는 검사가 아닙니다.

## 자동 검사 결과
- 전체 회귀 검사 543개 실행: 541개 통과, 분류 변경 전의 테스트 기대값/주입 컨텍스트 2건 실패.
- 두 테스트를 실제 새 분류에 맞게 수정한 뒤 해당 모듈 23개 재검사 통과.
- 최종 관련 검사: 외부 조사 16, 외부 후보 7, 지도 8, 소재 9, 시설 8, 키·모델 설정 4, 시나리오·실제 평가 UI 9 = 61개 통과.
- 소재 UI 검사에서 발생한 3초 초기화 시간 초과는 30초로 조정 후 재검사 통과. 기능 검증은 유지.
- 지도 검사는 불화수소를 수소로 인식하지 않음, 웨이퍼의 산소 관리 언급을 산소 공급망으로 확장하지 않음, Fab 14를 본사 대신 공장 지역 개략점으로 표시함을 포함.
- 추가 화면 재검사 중 첫 앱 렌더링의 30초 시간 초과를 추적해, 기업 목록 구성 시 불필요하게 반복되던 소재 별칭 정규식 검사를 조기 제외하도록 개선했습니다.
- 위 최종 변경 후 전체 검사를 다시 한 번 실행한 것은 아닙니다.

## 실제 API 평가 (2026-10-30)
사용자 프로젝트의 같은 키·세션에서 Responses API를 호출했습니다. 키와 원문 API 응답은 저장소에 저장하지 않았습니다.

| 모델·사례 | 결과 | 확인 범위 |
|---|---|---|
| gpt-4.1-mini / 희토류 관세 | 출처 누락 재현 | 검색 완료 1회, 인용 0, 참조 URL 0, URL 검사 제외 0 |
| gpt-6.1-sol / 같은 관세 질문 | 답변·출처 표시 | 가정/정책 적용 구분, USITC·NYACOL 등 인용 |
| gpt-6.1-sol / SUMCO 300mm PW | 답변·출처 표시 | 제품 후보와 규격·승인·공급 여력 구분 |
| gpt-6.1-sol / HF49%·총 금속 ≤1 ppb | 답변·출처 표시 | 질량 농도와 불순물 기준 구분, 미확인 규격 명시 |
| gpt-6.1-sol / TSMC Fab 14 | 답변·출처 표시 | 공장 범위·자료 시점·다른 공장 전환 조건 구분 |

위 네 성공 사례는 간단 답변 모드입니다. 추가로 SUMCO PW 질문을 외부 후보 비교를 켜서 실행했고, Siltronic AG의 Polished wafers 후보·원문 발췌·규격 미확인 카드가 생성되는 것을 확인했습니다. 주소·좌표가 확인되지 않은 외부 후보는 지도 표시를 보류했습니다. 한 번의 모델 비교로 기존 모델이 항상 실패한다거나 새 모델이 항상 정확하다고 결론내리지 않습니다. 공통 UI의 새 세션 기본 모델과 외부 조사 CLI 기본값을 gpt-6.1-sol로 변경했으며, 사용자가 지정한 모델·환경변수는 유지합니다.

## 핵심 원문 대조
전체 답변의 모든 문장을 검증한 것은 아닙니다. 다음 핵심 연결을 원문에서 확인했습니다.
- [NYACOL 연마재 자료](https://www.nyacol.com/application/polishing/): 산화세륨의 STI·ILD CMP 용도, 슬러리 배합용 연마재 구분.
- [Siltronic PW 자료](https://www.siltronic.com/en/products/polished-wafers.html): 200~300mm 폴리시드 웨이퍼와 도펀트·표면 품질 범위.
- [DAIKIN HF TDS](https://www.daikinchemicals.com/library/pb_common/pdf/tds/Semicon_Etching_Agents/tds-hf-4950-E_ver01_Aug_2019.pdf): HF49/50 질량 농도 및 검사 항목. 해당 문서의 검사 항목을 총 금속 ≤1 ppb 보증으로 해석하지 않음.
- [TSMC 2025 20-F](https://www.sec.gov/Archives/edgar/data/1046179/000162828026025362/tsm-20251231.htm): 공장별 공정 표·지역·기준 시점 확인.

## 다시 실행하기
AI 분석 → 추가 자료·평가 도구 → 실제 AI 평가 → **관세·기업·소재·공장 4종 실제 검사**. API 호출 실패 시 나머지를 중단하며, 검색 근거 부족은 진단과 함께 보존합니다. 호출 성공과 원문 검증 완료는 별도 상태입니다.

CLI는 키를 환경변수로 설정한 환경에서 실행합니다. 키를 명령행 인수나 저장소에 넣지 않습니다.

```powershell
python tools/evaluate_external_research.py --live --case tariff --simple --output work/tariff-live.json
```

지원 사례: tariff, company, material, factory, vendor, route. human_semantic_review가 pending이면 원문 적합성 검토가 완료된 것이 아닙니다.
