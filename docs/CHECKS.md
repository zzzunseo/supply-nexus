- Streamlit AppTest: 앱 로딩 예외 없음

## 화면 관찰

- Codex 앱 내부의 좁은 미리보기에서 제목, 8공정 선택, 조건 입력,
  3개 지표와 지구본 컴포넌트가 로드된 것을 확인했습니다.

- 회전·클릭·시점 유지·화면 크기 변경은 코드에 구현했으나 실제 조작 검증은 남아 있습니다.

## 사용자가 직접 확인할 항목

- [ ] 브라우저를 넓게 열었을 때 구체가 잘리지 않고 완전히 둥글게 보이는가
- [ ] 드래그로 회전하고 마우스 휠 또는 +/− 버튼으로 확대·축소되는가
- [ ] 공정·시나리오를 바꿔도 카메라 위치가 유지되는가
- [ ] 지역 선택과 초기화 버튼만 시점을 의도적으로 바꾸는가
- [ ] 대만 중단 예시 선택 시 해당 거점과 직접 연결된 경로가 빨간색·점선으로 보이는가
- [ ] 정상 상태로 되돌리면 중단 표시가 해제되는가
- [ ] 8개 공정에서 주요 경로 목록·투입재·제목이 함께 바뀌는가
- [ ] 다른 공정 함께 보기를 끄면 선택한 공정의 경로만 남는가
- [ ] 거점 및 우측 경로를 클릭했을 때 상세 정보·강조가 바뀌는가
- [ ] 자동 회전을 켠 뒤 직접 드래그하면 회전이 멈추는가
- [ ] 상세 데이터 탭의 JSON 저장 버튼이 현재 표시 경로를 내려받는가

## 이번 단계의 범위

원문 프롬프트의 Phase 1~7을 수행한 결과가 아니라 사용자가 먼저 요청한 UI 단계입니다.
공정 점수와 병목 모델은 연결 전이므로 임의 점수를 표시하지 않습니다.
색·글꼴·테두리 토큰을 theme.py로 모았으며 정상/중단은 색과 라벨을 함께 사용합니다.
공급 데이터는 모두 예시이고, 지도 좌표는 도시 근사값입니다.
