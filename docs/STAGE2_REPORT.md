# supply_globe 2단계 완료 보고

2026-10-26 · 요청한 2단계만 구현하고 중단합니다.

## 구현 내용

- **기간 분리:** `rr_days`는 관측 기간으로만 사용합니다. 저장된 각 이슈의 `days`를 계산과 설정창 비교에서 그대로 유지합니다. “N일” 입력은 해당 이슈의 지속 기간으로 저장하며, 기간 미기재는 관측 기간과 관계없이 30일 가정입니다. 이슈는 모두 관측 1일째 시작합니다.
- **일별 타임라인:** 지구본 아래에 8개 공정의 공급 충족도(0~100)를 표시합니다. 기존 COLORS에 선 종류·기호·공정명을 함께 사용하며, `first_hit`는 큰 기호와 공정별 일수로 표시합니다. 범례에서 공정별 표시를 전환할 수 있습니다.
- **이슈 관리:** 활성 목록에서 현재 적용 기간을 확인하고 관리 창에서 개별 기간 저장·삭제를 실행합니다. 수정·삭제는 즉시 재계산합니다. 같은 대상에 새 이슈를 입력하는 기존 덮어쓰기 동작은 유지합니다. 개별 삭제나 전체 복구는 기존 동작대로 소재 레시피 선택·관측 기간을 초기화하지 않습니다.
- **가정 표시:** 원인 카드에 해당 소재의 재고 일수와 우회 한도를 가정으로 표시합니다. 부족이 없는 경우 활성 소재의 가정 범위를 표시합니다.
- **민감도:** 기준과 재고 ×0.5/×1.5, 우회 ×0.5/×1.5의 5가지 조건을 엔진으로 각각 계산합니다. 선택된 소재군의 활성 노드만 변경하고 원본 입력은 보존합니다. 재고는 365일, 우회 한도는 100%로 제한합니다. 예약 풀의 공급 능력·인증일·확대 기간 등은 고정하므로 우회 한도를 올려도 점수가 그대로일 수 있습니다.
- 민감도 표는 마지막 날 전체 병목 지수 및 기준 대비 변화와 **일별 전체 병목 지수의 기간 평균**을 표시합니다. 실제 생산량 평균이 아닙니다. 관측 마지막 날 회복해도 기간 중 피해 차이를 확인할 수 있습니다. 재고/우회 옵션을 끄면 해당 변수의 민감도 변화는 없습니다.
- **100vh:** 1280×720과 1440×900에서 지구본·타임라인·제출 버튼이 화면 높이 안에 있는 것을 확인했습니다. 원인·민감도 영역은 내용이 길면 내부 스크롤을 사용합니다. 임시 브라우저 크기 설정은 검증 후 복원했습니다.

## 범위와 해석

이번 단계는 화면과 계산 호출 경계만 수정했습니다. 근거 미확인 관계의 계산 제외, 팹별/평균 집계, 대체 인증 가정 보강, 공급사 조사 범위, 장비 별도 모델, 별칭 확장, 항로 우회/항공 운송은 수정하지 않았습니다. 점수는 기존 가정 모델의 공급 충족도이며 실제 공정 가동률 예측치가 아닙니다.

관세는 기존 엔진의 별도 조건부 비용 지수를 유지하며, 일별 공급 부족/회복 차트의 적용 대상은 공급 중단 이슈입니다. 엔진의 관세 비용 지수를 기간별 비용 모델로 바꾸지는 않았습니다.
