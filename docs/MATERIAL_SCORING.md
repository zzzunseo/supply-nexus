# 공정별 직접 소재 충족도 계산으로 전환

2026-10-27 수정. 실행 주소는 http://localhost:8517/ 이며 8520도 동일 프로젝트입니다.

## 계산 경계
- 공정은 모델에서 필수로 설정한 직접 투입 소재·가스·웨이퍼·소모품의 충족도를 계산합니다.
- 소재별 기존 공급 + 실제 소진한 재고 보완 + 예약 한도 내 대체 공급을 합산하고 100을 상한으로 합니다. 기존의 재고·인증 대기·확대 기간·공유 예약풀 제한과 물류 우회 조건을 유지했습니다.
- 같은 소재의 병렬 공급자는 등록된 비중으로 합산합니다. 실제 비중이 없는 기존 경로는 균등 가정임을 유지합니다. 공정은 필수 소재 중 최저값을 사용합니다.
- 앞 공정의 점수와 생산 기업 자체 가동률을 다음 공정 소재 점수로 전파하지 않습니다. 생산 기업이 소재 공급자이기도 하면 등록된 소재 공급 경로의 감소는 해당 소재에 반영됩니다.
- 원재료 → 가공 소재 공급 경로는 유지합니다. 여러 공정이 같은 소재를 직접 사용하면 함께 감소할 수 있습니다.
- 장비 공급은 점수에서 제외하고 조달·증설·교체 위험으로 해설합니다. 기존 장비 고장·정비 차질의 가동 손실도 별도 정보 없이는 예측하지 않습니다.
- 관세는 소재 점수에서 제외하고 조건부 대상 수입재 가격지수 및 비용 해설로 분리합니다. 실제 제품 원가와 다릅니다.
- 물류 차질은 실제 모델에 등록된 소재 운송 경로의 도착량과 재고에만 반영합니다. 제외 장비 경로가 소재 우회 처리량을 소비하지 않습니다.

## 미산정과 부분 산정
활성 소재 입력이 없는 공정은 None/미산정으로 표시하고 최저값·평균에서 제외합니다. 기본 EDS는 미산정입니다. 기본 패키지도 소재 레시피를 활성화하지 않으면 미산정이며, 앱 기본값인 주석 솔더 레시피를 선택하면 해당 소재 기준으로 산정됩니다. 누락된 필수 소재 제약이 있는 공정의 * 표시를 유지하고, 그 누락을 다음 공정으로 자동 전파하지 않습니다. 100도 등록된 범위·가정의 소재 확보 지표일 뿐 실제 정상 생산을 뜻하지 않습니다.

## 화면·해설
왼쪽은 최저 소재 충족도·부족 공정 수·미산정 공정 수를 표시합니다. 공정별 직접 소재 부족과 후속 생산 위험을 분리하고 후속 감소율·발생일을 예측하지 않습니다. 첫 부족일은 현재 재고·대체 가정으로 계산한 소재 부족일이며 실제 생산 중단 예측일이 아닙니다. 오른쪽은 부족 소재명, 장비·관세 맥락과 불확실성을 설명합니다. 실제 LLM API는 아직 연결하지 않았습니다.

## 검증
전체 Python 304개 통과(75.964초), JavaScript 21개 통과. 신규 소재 점수 검증 8개 포함. 기존의 공정 간 생산 전파·장비 가동 손실을 전제로 한 테스트는 새 계산 경계로 변경했습니다. 재고 소진 경계, 부분 손실, 공유 대체풀, 자격 대기, 물류 우회, 기업별 집계, 제외 관계와 입력 검증을 포함합니다.

실제 브라우저에서 포토레지스트 중단 시 포토만 60으로 감소하고 식각·증착·금속배선은 100을 유지하는 화면을 확인했습니다. 장비 제한 입력에서는 소재 점수 100 유지와 장비 위험 해설을 확인했습니다. EDS는 미산정으로 표시됩니다. 수치는 시연 가정입니다.
